Core Capabilities

Everything a café needs.
Nothing it doesn't.

Real-Time Sync

4 WebSocket gateways keep tables, kitchen displays, notifications, and cross-device data perfectly in sync across all connected clients.

/tables/kitchen/sync/notifications

Role-Based Access

5 roles (Owner, Manager, Cashier, Waiter, Chef) with granular RBAC on every endpoint. JWT + refresh token auth with session verification.

Multi-Tenant

Complete data isolation per café with tenant-scoped queries, Row-Level Security, and per-branch filtering throughout the stack.

Offline-First

Operation queue with retry logic, network detection health endpoints, and automatic batch sync when connectivity is restored.

Kitchen Display

Priority-scored kitchen queue (critical → rush → normal) based on elapsed time. Real-time item-level status tracking for chefs.

Billing & Invoicing

Full payment lifecycle (cash, card, digital wallets), split payments, refunds, invoice generation, and financial audit trails.
